# Laboratorios Virens — web (lvirens.com)

Next.js 15 · TypeScript · Tailwind CSS v4 · exportación estática a cdmon.

- **Personas:** empieza por [`EMPEZAR-AQUI.md`](EMPEZAR-AQUI.md) o, si es la primera vez con
  código, [`GUIA-PRINCIPIANTES.md`](GUIA-PRINCIPIANTES.md).
- **Asistentes de IA:** reglas en [`CLAUDE.md`](CLAUDE.md) (o [`AGENTS.md`](AGENTS.md)); estado
  en [`TRASPASO.md`](TRASPASO.md).

```bash
npm install
npm run dev            # http://localhost:3000
npm run typecheck
npm run build:static   # web estática en out/ + zip para cdmon
```
